## 1. Обработка платежей

1.1. Платежи в российских рублях на Сайте обрабатывает платёжный сервис **ЮKassa**, сертифицированный по стандарту безопасности данных индустрии платёжных карт (**PCI DSS**) **Level 1** — высшему уровню сертификации для организаций, обрабатывающих карточные платежи. Платежи в долларах США обрабатывает международный платёжный провайдер **Stripe** или **UnitPay** — в зависимости от способа, указанного на странице оплаты.

1.2. Реквизиты карты (номер, срок действия, код CVV/CVC, имя держателя) вводятся только на защищённой платёжной странице платёжного сервиса. **Мы не получаем, не обрабатываем и не храним реквизиты карт держателей** — ни на серверах, ни в базах данных, ни в переписке.

1.3. От платёжного сервиса мы получаем только сведения, необходимые для подтверждения заказа: статус платежа, сумму, валюту, идентификатор платежа и, при наличии, маскированный номер карты (например, 4111 11** **** 1111).

## 2. Защищённая передача данных

2.1. Все данные между вашим браузером и Сайтом, а также между Сайтом и платёжным сервисом передаются по зашифрованному соединению с использованием протокола **TLS** (HTTPS). Сайт использует действующий SSL/TLS-сертификат.

2.2. Карточные платежи подтверждаются по технологии **3-D Secure** (Visa Secure, Mastercard Identity Check), если её поддерживает банк-эмитент: платёж может потребовать ввода одноразового кода от вашего банка.

2.3. Уведомления о статусе платежа от платёжного сервиса на наш сервер передаются по HTTPS и проверяются по цифровой подписи.

## 3. Регулярные платежи

3.1. При оформлении подписки платёжный сервис сохраняет токен вашего способа оплаты. По токену невозможно восстановить реквизиты карты; он используется только для списания стоимости подписки на согласованных вами условиях.

3.2. После отмены подписки токен перестаёт использоваться для списаний и удаляется или деактивируется в сроки, установленные платёжным сервисом.

## 4. Хранение конфиденциальной информации

4.1. Персональные данные покупателей (имя, email, телефон, данные заказа) хранятся на серверах с ограниченным доступом. Доступ предоставляется только сотрудникам и подрядчикам, которым он необходим для исполнения заказов и поддержки, и защищён индивидуальными учётными данными и аутентификацией по ключам.

4.2. Административный доступ к системам защищён паролями и ключами шифрования, которые не передаются третьим лицам.

4.3. Мы регулярно создаём резервные копии данных и храним их в защищённом хранилище с ограниченным доступом.

4.4. Персональные данные хранятся не дольше, чем необходимо для целей, указанных в Политике конфиденциальности.
