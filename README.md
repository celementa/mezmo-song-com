# mezmo-song.com

Посадочная сервиса персональных песен для международной аудитории. Юрлицо —
**Celementa FZCO** (Dubai Silicon Oasis, ОАЭ), цены в долларах, плечо
`variant3-990` ($25). Сайт статический: бэкенда, заказов и приёма оплаты пока
нет — анкета доходит до шага оплаты с суммой и обязательным согласием с
офертой, а сам платёж (UnitPay) подключается следующим этапом.

Код — перенос фронта из [ai-songs](https://github.com/gr1ffonner/ai-songs)
(`frontend/`, `packages/shared/`, коммит `a2d3ad2`); всё, что отличается от
mezmo.ru, — правки поверх него (см. историю).

## Команды

```bash
npm install
npm run dev        # Vite на :5173
npm run build      # frontend/dist
npm run check      # проверка бандла перед выкладкой
npm run typecheck
```

## Выкладка

Пуш в `main` → GitHub Actions (`.github/workflows/deploy.yml`): сборка, проверка
бандла, rsync в `/var/www/mezmo-song.com` на `109.248.42.189`, смоук по сайту.

- Ключ `DEPLOY_SSH_KEY` на сервере принадлежит пользователю `deploy-intl` и
  привязан к `rrsync /var/www/mezmo-song.com`: только запись файлов в эту папку.
  Ключ хоста — в `DEPLOY_KNOWN_HOSTS`.
- rsync идёт с `--delete-after`: **правки руками на сервере стираются** следующей
  выкладкой — всё меняется только в коде.
- Откат — `git revert` и пуш.

Сервер: Ubuntu 20.04, nginx 1.18 из apt (`/etc/nginx/sites-available/mezmo-song.com`,
SPA-фолбэк на `index.html`), Let's Encrypt через certbot с автопродлением.
DNS в GoDaddy: `@` и `www` → `109.248.42.189`.

## Что где

| Что | Где |
|---|---|
| Реквизиты компании, список юридических страниц | `frontend/src/lib/site.ts` |
| Тексты оферты, политик и согласия | `frontend/src/legal/*.md` (рендер — `routes/LegalPage.tsx`) |
| Цена, дизайн и тексты лендинга | `frontend/intl/settings.json` — снимок настроек mezmo.ru, вшивается в `index.html` при сборке |
| Анкета и шаг оплаты | `frontend/src/flow/IntlFlowRoute.tsx` |
| Футер с реквизитами и логотипами | `frontend/src/templates/gold.tsx`, `components/landing/PaymentLogos.tsx` |
| Маршруты | `frontend/src/router.tsx`: `/`, `/config`, `/terms`, `/privacy`, `/security`, `/consent`, `/contacts` |

Бэкенда нет, поэтому настройки не запрашиваются с сервера: `lib/settingsCache.ts`
отвечает вшитым снимком на любой запрос настроек. Аналитика mezmo.ru (GTM,
Метрика, Top.Mail.Ru) из `index.html` убрана, сайт закрыт от индексации
(`noindex`, `robots.txt`).

## Требования банка и UnitPay

| Требование | Где закрыто |
|---|---|
| Реквизиты юрлица | футер, `/contacts`, документы |
| Описание услуги и цена | лендинг (цена у кнопки «Создать песню»), шаг оплаты |
| Оферта, юрисдикция ОАЭ / суды Дубая | `/terms` |
| Условия возврата, отмены, доставки, оплаты | `/terms`, разделы 3, 5, 6 |
| Политика информационной безопасности | `/security` (приложение 1 к оферте) |
| Политика обработки персональных данных | `/privacy` |
| Согласие на обработку, передачу и хранение ПДн | `/consent` |
| Согласие с офертой при оплате | обязательная галочка на шаге оплаты, без неё кнопка неактивна |
| Логотипы платёжных систем | футер и шаг оплаты |
